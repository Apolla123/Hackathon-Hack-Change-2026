# Папка базы знаний Energytool

Положите сюда материалы кейса (формат: .md, .txt, .json, .jsonl, .csv, .pdf).
Бот берёт факты о продуктах только из этих файлов. Файлы кейса нельзя публиковать в открытых репозиториях,
поэтому `data/kb/*` добавлен в `.gitignore`.

- `.md`: каждый заголовок (`#`, `##`) начинает новый фрагмент.
- `.json`/`.jsonl`: объекты с полями `title` и `text` (также `content`, `body`, `description`).
- `.csv`: каждая строка становится фрагментом.
- `.pdf`: нужна библиотека `pdfplumber` (`pip install pdfplumber`, в базовый образ не входит).

После добавления файлов перезапустите сервис. Для ускорения и точности можно заранее посчитать эмбеддинги:
`python scripts/build_index.py`.
